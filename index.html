Made for real interfaces

A small foundation for Windows 8-inspired experiences. Public classes use the w8- prefix to avoid clashes with application styles.

01 / MODERN UI

Start Screen tiles

Responsive tile grids with wide, tall, and large modifiers, plus a palette of solid colors inspired by Windows 8.

02 / CONTROLS

Common UI elements

Buttons, fields, toggles, progress, badges, notices, and tabs in a simple flat visual language, with Font Awesome 4.7.0 icons.

03 / DESKTOP

Window chrome

Desktop-style windows, title bars, app bars, and native dialog styling, without pretending CSS supplies behavior.

04 / SHELL

The rest of the shell

Lock screen, live tiles with badges and flips, taskbar with tray and clock, flyouts, toasts, hubs, and snapped split views.
