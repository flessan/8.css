8.css

A CSS-only UI library for building faithful, Windows 8-inspired interfaces.

WINDOWS 8CSS ONLYFRAMEWORK NEUTRALPRE-RELEASE

8.css styles semantic HTML with the flat, colorful language of Windows 8. It includes the Start Screen tile system, common controls, app bars, and desktop window chrome. It does not ship a JavaScript runtime and works with plain HTML, React, Vue, Svelte, or another framework that can load CSS.

The documentation follows a component-by-component structure: each section introduces a component, shows a rendered preview, and provides source markup that can be copied into a project.

Installation / Usage

8.css is being prepared for its first public npm release as `@flessan/8.css`. The intended consumer workflow is to install the published package, rather than install source directly from GitHub.

Pre-release notice

The first npm release is pending. Once `@flessan/8.css` is published, use these commands to install it.

npm package

Install the package from the public npm registry:

npm install @flessan/8.css
Show usage
import "@flessan/8.css";

For a plain HTML page, use the CDN build served from the npm package:

<link rel="stylesheet" href="https://unpkg.com/@flessan/8.css/dist/8.css" />
Show code
<link rel="stylesheet" href="https://unpkg.com/@flessan/8.css/dist/8.css" />

Modular stylesheets

For smaller bundles, load the shared base stylesheet first, then your component styles and responsive.css. The full dist/8.css file already combines every module.

import "@flessan/8.css/dist/gui/base.css"; import "@flessan/8.css/dist/gui/tiles.css"; import "@flessan/8.css/dist/gui/buttons.css"; import "@flessan/8.css/dist/gui/responsive.css";
Show code
import "@flessan/8.css/dist/gui/base.css";
import "@flessan/8.css/dist/gui/tiles.css";
import "@flessan/8.css/dist/gui/buttons.css";
import "@flessan/8.css/dist/gui/responsive.css";

base.css defines the shared color and typography tokens. Each component stylesheet is a CSS file, not a JavaScript component.

Start Screen and Tiles

The tile system is the main Windows 8 identity of this library. Use the grid container and compose size and color modifiers on each link or button.

Size modifiers: w8-tile--wide, w8-tile--tall, and w8-tile--large. Colors include blue, cyan, purple, magenta, green, orange, red, and dark.

MMail2 new messagesPPhotosDDesktop08CalendarWWeather
Show code
<div class="w8-tiles">
  <a class="w8-tile w8-tile--wide w8-tile--blue" href="#mail">
    <span class="w8-tile__label">Mail</span>
  </a>
  <a class="w8-tile w8-tile--purple" href="#photos">
    <span class="w8-tile__label">Photos</span>
  </a>
</div>

Button

Use native buttons for actions. The primary modifier uses the Windows blue accent; the subtle modifier removes the solid fill for low-priority commands.

Show code
<button class="w8-button" type="button">Cancel</button>
<button class="w8-button w8-button--primary" type="button">Save changes</button>
<button class="w8-button w8-button--subtle" type="button">More options</button>

Text fields

Use visible labels with native input, select, and textarea elements. The field wrapper keeps labels, controls, and help text aligned.

This is shown on your profile.
Show code
<div class="w8-field">
  <label class="w8-label" for="display-name">Display name</label>
  <input class="w8-input" id="display-name" name="displayName" />
  <p class="w8-help">Shown on your profile.</p>
</div>

Checkbox and Toggle

Checkboxes and radio buttons stay native HTML controls. The toggle class only changes a checkbox visually; checked state still comes from the browser.

Show code
<label class="w8-toggle">
  <input class="w8-toggle__input" type="checkbox" checked />
  <span>Wi-Fi</span>
</label>

Tabs

Tab classes style a selected item and its bottom indicator. They do not implement keyboard navigation, switching panels, or ARIA state management.

This is a visual example of the selected tab state.

Show code
<div class="w8-tabs" role="tablist" aria-label="Settings sections">
  <button class="w8-tab" type="button" role="tab" aria-selected="true">Personalize</button>
  <button class="w8-tab" type="button" role="tab" aria-selected="false">Accounts</button>
</div>

Window

Compose a title bar, body, and footer to build Windows 8 desktop-style windows. The controls are visual only unless you connect them to application behavior.

Display settings

Adjust your display preferences.

Show code
<section class="w8-window" aria-labelledby="window-title">
  <header class="w8-title-bar">
    <span class="w8-title-bar__text" id="window-title">Display settings</span>
  </header>
  <div class="w8-window-body"><p>Adjust your display preferences.</p></div>
  <footer class="w8-window-footer">
    <button class="w8-button w8-button--primary" type="button">Apply</button>
  </footer>
</section>

App Bar

The app bar groups commands into a dark Windows 8-style action surface. Use native buttons or links and label the navigation region.

Show code
<nav class="w8-app-bar" aria-label="Document actions">
  <button class="w8-app-bar__item" type="button">Share</button>
  <button class="w8-app-bar__item" type="button">Select</button>
</nav>

Dialog Box

Dialog styles apply to native HTML dialog elements. This visible preview is a styled container; in an app, use the browser dialog API to open and close a real dialog.

Delete this file?

This action cannot be undone.

Show code
<dialog class="w8-dialog" aria-labelledby="confirm-title">
  <div class="w8-dialog__body">
    <h2 id="confirm-title">Delete this file?</h2>
    <p>This action cannot be undone.</p>
  </div>
  <div class="w8-dialog__footer">
    <button class="w8-button" type="button">Cancel</button>
    <button class="w8-button w8-button--primary" type="button">Delete</button>
  </div>
</dialog>

Origin and Inspiration

8.css is very strongly inspired by 7.css by khang-nd, especially its focus on semantic HTML, a CSS-only UI layer, detailed component documentation, and examples that pair a visual preview with copyable markup. 8.css is not an official continuation of 7.css and does not claim affiliation with its author.

The initial code came from Windows-8-Metro-UI by SamWanekeya. That repository was a small Start Screen experiment with no recorded commits after June 2017. It appeared to be abandoned, so I forked it and began evolving it into a reusable component library with modular CSS source and developer-focused documentation.

The original MIT license is preserved. The goal is to make the package installable from npm so consumers do not need GitHub URLs to install or use it.
