8.css

A CSS-only UI library for building faithful, Windows 8-inspired interfaces.

WINDOWS 8CSS ONLYFRAMEWORK NEUTRALFONT AWESOME 4.7SHELL SURFACES

8.css styles semantic HTML with the flat, colorful language of Windows 8. It includes the Start Screen tile system and its live tiles, common controls, the Charms bar and flyout panes, a lock screen, the desktop taskbar, hubs and snapped split views, desktop window chrome, and the complete Font Awesome 4.7.0 icon font. It does not ship a JavaScript runtime and works with plain HTML, React, Vue, Svelte, or another framework that can load CSS.

The documentation follows a component-by-component structure: each section introduces a component, shows a rendered preview, and provides source markup that can be copied into a project.

Installation / Usage

The public package is available as @flessan/8.css on npm. The stylesheet bundles Font Awesome 4.7.0 together with 8.css, and the icon font files are published in the package, so icons never depend on a third-party CDN.

Bundled icon font

dist/8.css contains the Font Awesome 4.7.0 stylesheet and points at dist/font-awesome/fonts/. For modular setups, load dist/font-awesome/css/font-awesome.min.css yourself.

npm package

Install the package from the public npm registry:

npm install @flessan/8.css
Show usage
import "@flessan/8.css";

For a plain HTML page, use the CDN build served from the npm package:

<link rel="stylesheet" href="https://unpkg.com/@flessan/8.css/dist/8.css" />

Modular stylesheets

For smaller bundles, load the shared base stylesheet first, followed by the component modules you need. Load the standalone Font Awesome stylesheet for glyphs, then icons.css for the 8.css sizing and icon-button helpers. The full dist/8.css file already combines the icon stylesheet and every CSS module.

import "@flessan/8.css/dist/font-awesome/css/font-awesome.min.css"; import "@flessan/8.css/dist/gui/base.css"; import "@flessan/8.css/dist/gui/tiles.css"; import "@flessan/8.css/dist/gui/buttons.css"; import "@flessan/8.css/dist/gui/icons.css"; import "@flessan/8.css/dist/gui/responsive.css";

Personalize: wallpaper and accent

The Start Screen reads two custom properties, so any Windows 8 or 8.1 wallpaper can sit behind the tiles without extra CSS: --w8-start-image takes a background image and --w8-start-background is the solid fallback colour painted while it loads. --w8-accent colours controls over the wallpaper.

Lock Screen

The lock screen is a full-bleed image with the time, date and system status along the bottom edge. It is the first surface a Windows 8 user sees, so the component keeps the same reading order: time, date, an optional detailed status from one app, then network and battery. Point it at any image with --w8-lock-image, or leave it to the solid --w8-lock-background.

Origin and Inspiration

8.css is very strongly inspired by 7.css by khang-nd, especially its focus on semantic HTML, a CSS-only UI layer, detailed component documentation, and examples that pair a visual preview with copyable markup. 8.css is not an official continuation of 7.css and does not claim affiliation with its author.

The initial code came from Windows-8-Metro-UI by SamWanekeya. That repository was a small Start Screen experiment with no recorded commits after June 2017. It appeared to be abandoned, so I forked it and began evolving it into a reusable component library with modular CSS source and developer-focused documentation.

The original MIT license is preserved. The goal is to make the package installable from npm so consumers do not need GitHub URLs to install or use it.
