# Documentation

8.css is a CSS-only UI library inspired by Windows 8 Modern UI / Start Screen and desktop.

- [Installation](installation.md): CDN, GitHub installation, and local development.
- [Component reference](components.md): current public classes and markup patterns.
- [Customization](customization.md): CSS tokens, tile colors, and local overrides.
- [Accessibility](accessibility.md): semantic markup, focus, controls, and motion.
- [AI agent guide](ai-agents.md): discoverable docs and agent workflows.
- [Library showcase](../index.html)
- [Legacy Start Screen prototype](../examples/legacy-start-screen.html)

The API is at an early foundation stage. Treat selectors in the current stylesheet as the implemented API.
