# Wallpaper pack notice

The images in `styles/images/Windows8RTM/` and
`styles/images/Windows8.1RTMWallpapers/` are the default desktop wallpapers
that shipped with **Windows 8** and **Windows 8.1** (RTM). They are included in
this repository only so the 8.css demo site and examples can show the library
on the artwork it was designed for.

## What is generated

`styles/images/wallpapers/` contains tooling output, not new artwork:

| File | Purpose |
| --- | --- |
| `manifest.json` | Catalogue of every wallpaper: id, curated title, source file, dimensions, byte size, aspect ratio, monitor span, dominant and accent colours. Generated by `node scripts/wallpapers.mjs`. |
| `palette.json` | Dominant and accent colour per wallpaper, sampled from a downscaled copy. |
| `thumbs/<id>.jpg` | 480 × 300 progressive JPEG thumbnails used by the gallery page. |
| `wallpapers.css` | Optional `.w8-wallpaper-<id>` classes that set `--w8-start-image`, `--w8-start-background` and `--w8-accent`. |

## Regenerating the derived files

The manifest and stylesheet are dependency-free:

```sh
node scripts/wallpapers.mjs
```

Thumbnails and colours need an image decoder. The committed versions were made
with Python and Pillow; rerun this recipe after adding or replacing a wallpaper:

```python
from PIL import Image
import json, os, glob

sources = [
    ("win8",  "styles/images/Windows8RTM",             "Windows 8 RTM"),
    ("win81", "styles/images/Windows8.1RTMWallpapers", "Windows 8.1 RTM"),
]
palette = {}
for prefix, folder, _ in sources:
    for path in sorted(glob.glob(f"{folder}/*"), key=lambda p: (len(p), p)):
        wid = f"{prefix}-{os.path.splitext(os.path.basename(path))[0].lower()}"
        image = Image.open(path).convert("RGB")
        thumb = image.copy()
        thumb.thumbnail((480, 300), Image.LANCZOS)
        thumb.save(f"styles/images/wallpapers/thumbs/{wid}.jpg",
                   "JPEG", quality=78, optimize=True, progressive=True)
        sample = image.resize((80, 50), Image.LANCZOS)
        pixels = list(sample.getdata())
        dominant = tuple(sum(p[i] for p in pixels) // len(pixels) for i in range(3))
        buckets = {}
        for pixel in pixels:
            buckets.setdefault(tuple(v // 32 for v in pixel), []).append(pixel)
        def saturation(pixel):
            top = max(pixel)
            return (top - min(pixel)) / top if top else 0
        group = max(buckets.values(), key=lambda bucket: len(bucket) * saturation(
            tuple(sum(p[i] for p in bucket) // len(bucket) for i in range(3))))
        accent = tuple(sum(p[i] for p in group) // len(group) for i in range(3))
        palette[wid] = {"dominant": "#%02x%02x%02x" % dominant,
                        "accent": "#%02x%02x%02x" % accent}
json.dump(palette, open("styles/images/wallpapers/palette.json", "w"), indent=2, sort_keys=True)
```

Then rerun `node scripts/wallpapers.mjs` to refresh the manifest and stylesheet,
and `npm test` to verify that every wallpaper has a thumbnail and a palette entry.
